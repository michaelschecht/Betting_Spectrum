# The Edge Spectrum Icon Proposals

Square The Edge Spectrum icon proposals for favicons, app icons, and clickable buttons.

Open [`../preview.html`](../preview.html) to compare these icons alongside the landscape logo proposals.

## Dark Icons

- [Edge Gradient](./dark/favicon-01-edge-gradient.svg) - a positive-to-negative edge axis with a central break-even point.
- [Horizon Bars](./dark/favicon-02-horizon-bars.svg) - time-horizon return bars crossing a baseline.
- [Risk Spectrum](./dark/favicon-03-risk-spectrum.svg) - a curved return path over a risk spectrum divider.

## Light Icons

- [Edge Gradient Light](./light/favicon-01-edge-gradient-light.svg) - light version of the edge gradient concept.
- [Horizon Bars Light](./light/favicon-02-horizon-bars-light.svg) - light version of the horizon bars concept.
- [Risk Spectrum Light](./light/favicon-03-risk-spectrum-light.svg) - light version of the risk spectrum concept.

## Notes

- All links are relative to this README, so they keep working if the entire proposal folder is moved.
- Icon assets use a `256 x 256` viewBox and are safe for square favicon export.
- SVG format keeps the marks crisp for browser favicons, toolbar buttons, app tiles, README banners, and documentation art.
